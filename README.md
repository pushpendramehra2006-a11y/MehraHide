# Mehra Hide

Ek tap me chune hue apps, unki notifications aur photo/video folders chhupa do. OFF (PIN ke saath) karne par sab wapas.

## Features
- Apna launcher: ON hone par chune hue apps ke icon home screen se gayab
- Chune hue apps ki notifications block (NotificationListenerService)
- Photo/Video folders gallery se hide (.nomedia)
- OFF karne ke liye optional PIN

## Build
1. Android Studio (Ladybug ya naya) me is folder ko open karo (Gradle wrapper khud ban jaayega)
2. Run karo
3. App ke Control tab me: Notification access, All files access, Default launcher set karo

## Limits
- Settings > Apps me app dikh sakta hai
- File manager me folder dikh sakta hai
